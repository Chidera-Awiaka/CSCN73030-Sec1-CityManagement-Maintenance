Detailed Description

Weather alerts from E-services. ESV-03 - Receive weather alerts (stored with external ID, content, area, severity, validity; never creates interventions or changes priorities automatically). ESV-04 - Record an assessment (Awaiting Review / Reviewed; reviewer, date, decision, rationale). ESV-05 - Take action (create intervention, link interventions, no action required, reschedule or put linked work on hold); every decision stays attached to the alert.
