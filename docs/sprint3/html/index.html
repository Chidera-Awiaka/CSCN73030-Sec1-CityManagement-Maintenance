Headers: user actions send X-User-Id (recorded in the audit history). Messages from other services must send X-Source-Service (E-services, Budget, Security, Public Transport); anything else is refused with 403 — so Maintenance users cannot record Budget or Security decisions on those teams' behalf.

BUD-04 (pending confirmation) is off by default. To enforce "no In Progress without an approved budget", set "Budget": { "RequireApprovalToStart": true } in backend/Maintenance.Api/appsettings.json.
