Detailed Description

Security integration. SEC-01 send an assistance request (reason, location, period, intervention ID; transmission status visible). SEC-02 receive Security's response (linked to the request; outcome and comments visible). Only the Security service can send a response, so Maintenance users cannot approve on Security's behalf.
