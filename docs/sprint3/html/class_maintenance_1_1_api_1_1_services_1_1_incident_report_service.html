Detailed Description

Receives incident reports from E-services and lets a maintenance agent accept or reject them. Accepting a report creates a new intervention through InterventionService (MNT-01). Reports are saved to a JSON file so they survive a restart.

Related requirements: ESV-01 - Receive incident reports from E-services ESV-02 - Accept or reject a report
