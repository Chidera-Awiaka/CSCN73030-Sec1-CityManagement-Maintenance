Detailed Description

Business logic for maintenance interventions. Interventions are kept in memory and saved to a JSON file so they survive a restart of the service.

Related requirements: MNT-01 - Create an intervention MNT-02 - View and filter interventions MNT-03 - Prioritize interventions MNT-04 - Schedule an intervention MNT-05 - Assign technicians or teams MNT-07 - Update intervention operational status

Returns interventions matching the supplied filters (MNT-02). Any empty filter is ignored.

Matching is case-insensitive. Location matches when it contains the supplied text.

Results are sorted by priority and then creation date.
