Detailed Description

Tracks every exchange with external services and supports retries (TEC-04).

  • Outbound: each message has an idempotency key; a message that already succeeded is never sent again, so retries and double-clicks do not create duplicate requests or updates.
  • Failed outbound messages stay visible with their error and can be retried.
  • Inbound: each message is recorded under the sender's external ID so a repeated delivery is detected and not processed twice.
