Detailed Description

Integration boundary with the Property Registration service of the City Management Enterprise System. Related requirements: REG-01, REG-02.

Sprint 2 uses MockPropertyRegistry (allowed by REG-01 while the Property Registration service is not available). When that service publishes its REST API, a client implementing this interface replaces the mock in Program.cs; the controllers and tests do not change.
